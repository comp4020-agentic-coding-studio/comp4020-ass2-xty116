## The question

“Higher value, higher note” is only one design. We compare linear and
logarithmic scales, continuous and discrete pitch, loudness limits, stereo
position and tempo. The test is not whether a result sounds pleasant, but
whether its perceptual ordering matches the intended data relationship.

## Signal chain

Scalar values → choose data domain → choose auditory range → define scale →
listen for discriminability → publish the rule. A mapping legend must let
another person reconstruct the operation without hearing the artefact.

The lab uses the same sequence for three mappings, creating a controlled
comparison rather than three unrelated compositions.
