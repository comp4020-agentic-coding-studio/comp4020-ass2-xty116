## The question

Clean playback can imply certainty that the data does not have. We compare
three strategies: a second voice for confidence bounds, timbral roughness for
uncertainty magnitude, and explicit silence for missing samples.

## Signal chain

Value plus error and quality flag → keep each field separate → map value to
pitch, error to a bounded timbral cue, quality flag to an announcement →
provide the same fields as a table. Interpolation is never silent.

Students run a small recognition test to learn whether the uncertainty channel
clarifies or masks the primary pattern.
