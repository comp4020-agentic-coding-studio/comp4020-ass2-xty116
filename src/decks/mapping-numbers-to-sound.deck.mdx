# Mapping numbers to sound

<p className="lede">A mapping is a model: it decides which difference a listener is allowed to notice.</p>

## Data frequency is not automatically pitch

<div className="deck-grid three">
  <div className="metric gold"><strong>1 Hz</strong><span>one event per second: below ordinary musical pitch</span></div>
  <div className="metric"><strong>440 Hz</strong><span>an audible reference pitch, conventionally A4</span></div>
  <div className="metric warm"><strong>×440</strong><span>a possible scaling operation that must be disclosed</span></div>
</div>

The same word, **frequency**, can name a measured repetition rate or an audio oscillator. Do not collapse them.

---

## Linear or logarithmic?

<table className="mapping-table">
  <thead><tr><th>Input</th><th>Linear pitch</th><th>Log pitch</th></tr></thead>
  <tbody>
    <tr><td>1</td><td>220 Hz</td><td>220 Hz</td></tr>
    <tr><td>10</td><td>260 Hz</td><td>440 Hz</td></tr>
    <tr><td>100</td><td>660 Hz</td><td>880 Hz</td></tr>
  </tbody>
</table>

Linear mapping preserves equal **differences**. Log mapping foregrounds equal **ratios**. The task chooses the scale.

Continuous pitch keeps small differences. Quantised notes are memorable, but they invent thresholds that the data did not contain.

## One sound dimension, one first job

<div className="deck-grid three">
  <div className="panel gold"><p className="panel-title">Time</p><p>sample order</p></div>
  <div className="panel"><p className="panel-title">Pitch</p><p>measured value</p></div>
  <div className="panel warm"><p className="panel-title">Timbre</p><p>quality flag</p></div>
</div>

When two data dimensions compete for pitch, a listener cannot know which one moved. Independence is a design resource.

## Three mappings of one sequence

<table className="mapping-table">
  <thead><tr><th>Sequence</th><th>Rule</th><th>Question supported</th></tr></thead>
  <tbody>
    <tr><td>2, 4, 8, 4, 2</td><td>value → pitch</td><td>where is the maximum?</td></tr>
    <tr><td>2, 4, 8, 4, 2</td><td>value → interval</td><td>where does pacing slow?</td></tr>
    <tr><td>2, 4, 8, 4, 2</td><td>value → timbre</td><td>which category dominates?</td></tr>
  </tbody>
</table>

The source is fixed. The supported inference changes.
