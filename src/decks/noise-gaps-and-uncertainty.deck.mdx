# Noise, gaps and uncertainty

## Clean sound can overstate certainty

SLOP3255 · Week 9

---

{/* _class: compact */}

## A value is not alone

A scientific table may include:

- measured value
- uncertainty interval
- quality flag
- timestamp
- missing-data code

Sonifying only the central value removes part of the evidence.

---

## Missing is not zero

Zero is a measurement.

Missing means no valid value is available.

Interpolation is a modelled estimate.

If all three become silence, a listener cannot distinguish them.

---

## Three uncertainty channels

**Second voice:** hear upper and lower bounds  
**Timbre:** increase roughness with uncertainty  
**Event cue:** announce low-confidence or missing regions

Each channel competes with the primary pattern. Make it switchable.

---

## Test the uncertainty task

Ask a listener to:

- locate the least certain region
- distinguish a gap from a measured minimum
- compare patterns with uncertainty on and off

Record errors, not just preferences.

# Make uncertainty audible

Keep the original value, error and quality fields visible.
